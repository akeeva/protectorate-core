# Protectorate Brand Guide
**Version:** 1.0

---

# Purpose

This document defines the official visual identity of The Protectorate.

All project artwork, documentation, interfaces, and promotional material should follow these standards.

---

# Design Philosophy

The Protectorate values:

- Security
- Precision
- Reliability
- Simplicity
- Consistency

Every visual element should reinforce those values.

---

# Official Tagline

> Secure. Modular. Uncompromising.

---

# Logo

The official Protectorate shield is the only approved logo.

Do not:

- redraw it
- alter its proportions
- recolor it
- stretch it
- invent alternate shield designs

---

# Wordmark

Official:

PROTECTORATE
CORE

White primary text.

Purple accent.

No alternate typography.

---

# Color Palette

Primary Background:
Black / Charcoal

Primary Accent:
Protectorate Purple

Secondary Accent:
Blue

Primary Text:
White

Inactive Text:
Gray

---

# Typography

Headings:
Orbitron

Body:
JetBrains Mono

---

# User Interface

The Protectorate interface should feel like a professional engineering workstation.

Characteristics:

- Dark theme
- Purple highlights
- Minimal visual clutter
- Information-dense layouts
- Monospaced text
- Box drawing characters
- Consistent spacing

---

# Wallpapers

Only approved Protectorate wallpapers should be distributed.

---

# Canon Policy

Visual identity changes require an explicit new Brand Kit version.

Generated artwork does not become canonical until approved.
